# Academic RAG Assistant

A modular Retrieval-Augmented Generation (RAG) system for academic papers using:

- PyMuPDF
- LangChain
- Sentence Transformers
- ChromaDB

## Features

- PDF ingestion
- Text cleaning
- Semantic chunking
- Embedding generation
- Vector search

## Tech Stack

- Python
- SentenceTransformers
- LangChain
- ChromaDB
